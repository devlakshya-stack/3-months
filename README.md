# Satviki — Three Months

A frontend-only anniversary experience. No backend or build step is required.

## Run
Open `index.html` in a browser. For camera access, browsers may require a secure context (HTTPS or localhost). If camera access is unavailable, use Upload Photo.

## Personalize
Edit `content.js` first. Change the name, messages, ticket copy, timeline, gallery labels, quiz and song path.

## Real photos
For a polished final version, replace the gallery placeholders in `app.js` or add your own local image paths and update the gallery renderer. The camera booth also supports direct uploads.

## Song
Set `song:'assets/our-song.mp3'` in `content.js` and put the audio file at that path.
